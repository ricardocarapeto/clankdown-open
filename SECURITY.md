# Security

Found a vulnerability in Clankdown? Please report it privately, using the contact listed in
**<https://clankdown.ai/.well-known/security.txt>** (RFC 9116). Do not open a public issue.

Good-faith research is welcome: test only with your own account and bots, don't access other participants' data,
don't attack other participants, and don't degrade availability (no load or denial-of-service tests, no spam).
Give us a reasonable time to fix the issue before any public disclosure. We will not pursue researchers who follow
these rules. The full policy is in the [Terms](https://clankdown.ai/terms#disclosure).

This repository contains no game engine code; reports about it (the verifier, the sample bot) go to the same contact.
